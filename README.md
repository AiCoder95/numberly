# Numberly · NumberGenTgBot

Публичное приложение: https://aicoder95.github.io/numberly/

Telegram-бот: https://t.me/NumberGenTgBot

Русскоязычное Telegram Mini App: числа, розыгрыши по списку, пароли, случайный выбор, команды, подбрасывание монетки. Статическое приложение без зависимостей и платного API. Исходники интерфейса — `dist/`.

## Локальный запуск

Нужен Node.js 22 или новее. В этой папке выполните `npm run dev`, откройте http://localhost:4173. Проверки: `npm test`. Сборка не требуется.

## Подключение к Telegram

1. Разместите содержимое `dist/` на публичном HTTPS-хостинге. Для самостоятельного бесплатного размещения можно использовать GitHub Pages с учётом текущих условий сервиса. Приватная ссылка предпросмотра Sites не подходит для массового запуска внутри Telegram.
2. В официальном @BotFather отправьте `/setmenubutton`, выберите @NumberGenTgBot, задайте текст «Открыть Numberly» и HTTPS-адрес приложения.
3. В настройках бота через `/mybots` → Bot Settings → Configure Mini App настройте Main Mini App, если нужен запуск из профиля бота. Названия пунктов Telegram могут отличаться по версии клиента.
4. Проверьте на Android и iOS: открытие, тёмная тема, клавиатура, скролл, копирование и скачивание TXT. Загрузка файла зависит от Telegram-клиента, копирование — от доступа к буферу обмена.

Токен бота для этого статического интерфейса не требуется. Никогда не добавляйте его в `dist/`, репозиторий или клиентский JavaScript.

## Что реализовано

- Равномерный выбор через `crypto.getRandomValues` с rejection sampling, уникальные выборки без выделения массива полного диапазона.
- Удаление точных дублей строк после trim. Разный регистр, разные имена и псевдонимы одного человека считаются разными строками.
- Генератор паролей с обязательным присутствием выбранных категорий. Пароли не сохраняются и не экспортируются в файл.
- Локальная история 30 результатов, скачивание TXT, копирование, светлый и тёмный режимы, фиолетовая, красная, зелёная и синяя темы, интеграция Telegram SDK и haptic feedback.
- Вставленные списки живут в памяти вкладки; история сохраняет результаты, а не полные списки участников. Хранилище не синхронизируется между устройствами.

## Ограничения первой версии

Нет сбора подписчиков, проверки подписки, получения комментариев, платежей, аккаунтов, серверной базы, картинки-сертификата или публично проверяемого протокола. Розыгрыш можно перезапустить: локальная случайность не доказывает честность организатора. Бот подключается владельцем через BotFather.

Все функции сейчас бесплатны. Раздел будущих возможностей — описание планов, а не действующая подписка. Оплата цифровых услуг внутри Telegram требует отдельного серверного внедрения с Telegram Stars; платежи ещё не подключены.
