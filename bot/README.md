# Подключение автоответов Numberly

`worker.js` отвечает в личных сообщениях на `/start`, `/help`, `/privacy` и вопросы об инструментах, а также показывает кнопку открытия мини-приложения. Он не работает в группах и не хранит тексты сообщений. Чтобы не отвечать на повторную доставку, Durable Object хранит ID события, хэш идентификаторов чата и сообщения, а также время обработки. Записи старше трёх дней удаляются при следующем обработанном сообщении.

## Что потребуется

- Аккаунт Cloudflare с опубликованным Worker `numberly-bot` и авторизованный Wrangler.
- Доступ к @BotFather и токен владельца `@NumberGenTgBot`.
- Node.js 22 или новее. Настроечная программа находится в `bot/connect.mjs`.

## Подключение через локальную страницу

1. Запустите в терминале из папки проекта: `node bot/setup-web.mjs`. Откройте выведенную локальную страницу в браузере.
2. Вставьте новый токен из BotFather в поле страницы: символы будут скрыты. Не отправляйте токен в чат и не сохраняйте его в файлы проекта.
3. Нажмите «Проверить бота». Программа проверит, что токен принадлежит именно `@NumberGenTgBot`, и предупредит, если уже настроен другой webhook.
4. Нажмите «Подключить бота». Программа создаст секрет, передаст его напрямую Wrangler, проверит доступность Worker и зарегистрирует webhook. Секрет и токен не сохраняются в репозитории.
5. Откройте `@NumberGenTgBot`, отправьте `/start` и нажмите несколько кнопок. Если у бота уже был другой обработчик, его работа будет заменена.

Для подключения через терминал можно вместо страницы запустить `node bot/connect.mjs`: токен вводится без отображения, а подтверждение выполняется словом `YES`.

Вы можете добавить команды `/start`, `/help`, `/privacy` и `/app` через @BotFather → `/setcommands`, но это необязательно для работы ответов.

## Если Worker ещё не размещён

Для автоматического размещения нужны установленный Wrangler и авторизация к вашему Cloudflare. Конфигурация находится в `wrangler.jsonc` и ссылается на `runtime.js`. По умолчанию используется Worker Numberly из текущего аккаунта; иной HTTPS-адрес можно передать первым аргументом команды. Не публикуйте токен бота в исходниках, GitHub или настройках сайта.

## Проверки

`node tests/bot.test.mjs` проверяет обработку команд, работу клавиатуры, защиту webhook и игнорирование групп. Инструкции про приложение отражают текущие ограничения: проверки подписок и публичного доказательства результата пока нет.

При проблемах проверьте, что Worker развёрнут, адрес введён точно, учётная запись Wrangler совпадает с аккаунтом Worker и выполнена авторизация. После настройки токен и секрет не нужны коду Worker: Telegram получает секрет при регистрации webhook и добавляет его к запросам.
